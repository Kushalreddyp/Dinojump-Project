# Dinojump-Project
BRIEF DESCRIPTION :     The motive of this project is to create an engaging, program-driven arcade game that is both entertaining and demonstrates core programming principles, including database management and GUI development. 
PROJECT OVERVIEW : 

 

DinoJump is a side-scrolling infinite runner game inspired by the classic Chrome Dino game. 

The player controls a Dinosaur character that must jump to avoid oncoming obstacles (cacti and birds). 

The game features a user authentication system, global leaderboards, and progressive difficulty. 

It includes a modern, monochrome minimalist design for an enhanced user experience. 

 

WHY I CHOSE THIS PROJECT : 

 

It provides a hands-on opportunity to integrate multiple programming concepts: GUI development with Tkinter, database management with MySQL, and game logic. 

The project demonstrates real-world application development with user accounts, data persistence, and a competitive scoring system. 

It serves as an excellent demonstration of object-oriented programming in Python. 

 

MODULES USED : 

 

USER AUTHENTICATION MODULE: Handles user signup, login, and session management. 

GAME ENGINE MODULE: Manages the core game of mechanics, physics, and rendering. 

LEADERBOARD MODULE: Tracks and displays global and country-specific high scores. 

DATABASE MODULE: Stores user credentials, high scores, and leaderboard data persistently. 

Applications and Tools Used 

 

 

PYTHON: 

 

Python is a high-level, general-purpose programming language. It is an interpreted language that emphasizes code readability with significant indentation. It is an object-oriented language that helps programmers write clear and logical code for both small and large projects. 

 

The major features of Python are – 

(i) It is an interpreted language. Hence, debugging is easier. 

(ii) It is platform-independent and hence can be used on any device and is compatible with all major operating systems. 

(iii) It is completely free of cost to download. It is also an open-source software. 

(iv) It is very simple to use since the language resembles the English language closely. Hence, it is very easy to learn how to write the commands and expressions. 

(v) It also has a rich library support such as the Python Standard Library that provides a variety of functions for use. 

 

TKINTER: 

 

Tkinter is Python's de-facto standard GUI (Graphical User Interface) package. It is the most commonly used method for creating graphical applications in Python due to its simplicity and availability with standard Python installations. 

Its unique features/characteristics are – 

(i) Easy to Learn: Tkinter provides a simple and intuitive interface for creating GUI elements. 

(ii) Cross-Platform: Tkinter applications can run on Windows, macOS, and Linux without modification. 

(iii) Widget Variety: It offers a wide range of widgets like buttons, canvases, labels, and entry fields that can be used to build interactive applications. 

(iv) Canvas for Graphics: The Canvas widget in Tkinter allows for drawing shapes, images, and creating animations, making it suitable for simple game development. 

 

STRUCTURED QUERY LANGUAGE (SQL): 

 

SQL (Structured Query Language) is a standardized language developed and used for accessing and modifying relational databases. The uses of SQL include modifying database table and index structures; adding, updating and deleting rows of data; and retrieving subsets of information from within a database. 

Its unique features/characteristics are – 

(i) It can be installed on various devices and is supported by a variety of operating systems. 

(ii) It is highly secure with password protection and also has the feature of providing excellent connectivity. SQL can be used as a back-end for projects and such connectivity can be established with Python. 

(iii) It is easy to use since it is a query-based language.
